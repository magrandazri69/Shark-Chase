# Shark-Chase 🦈

Game pixel ringkas — **jerung ikut jari kau!**

Gerakkan jari (telefon) atau tetikus (komputer), dan jerung pixel akan
mengejar gerakan kau. Makan ikan kecil untuk kumpul markah, tapi elak
ubur-ubur beracun 🪼 — kalau kena, game over!

## Cara main
1. Buka `index.html` dalam browser (HP atau komputer).
2. Tekan **MAIN**.
3. Gerakkan jari/tetikus untuk pandu jerung.
4. 🐟 Makan ikan = markah naik. 🪼 Kena ubur-ubur = mati.

Markah terbaik disimpan secara automatik dalam browser.

## Teknikal
- Satu fail sahaja (`index.html`), tiada `build`, tiada dependency.
- HTML5 Canvas + JavaScript tulen.
- Sokong sentuhan (touch) dan tetikus.

Nak main online? Hos guna GitHub Pages — pilih branch ini di
**Settings → Pages**, dan game akan terus boleh dimainkan.
